# Phase 01 Acceptance Criteria

## General

- App runs locally.
- No TypeScript errors.
- RTL works correctly.
- Main routes work.
- Design uses purple identity.
- UI is not overly game-like.
- Components are reusable.

## Child

- Child home shows mission, progress, badge, and wishes preview.
- No other child data appears.

## Parent

- Parent home shows linked child info only.
- Video approval appears as mock state.
- Wishes are visible as parent-only content.

## Teacher

- Teacher dashboard is usable on desktop.
- Pending videos are shown only as approved-by-parent mock state.
- Children table is organized.

## Guest

- Guest view has no private child data.
- No video, wishes, or teacher notes are visible.

## Code Quality

- Components are not giant files.
- Business mock data is separated from UI.
- No hardcoded repeated colors outside tokens unless justified.
