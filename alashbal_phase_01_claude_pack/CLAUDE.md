# CLAUDE.md — قواعد العمل على تطبيق الأشبال

أنت تعمل على تطبيق عربي RTL اسمه **الأشبال**.

## القاعدة الكبرى

لا تبنِ التطبيق كاملًا دفعة واحدة.
اشتغل على Feature واحدة أو Task واحدة فقط في كل مرة.

## ممنوعات صارمة

- لا تغيّر نطاق المهمة بدون طلب صريح.
- لا تضف مزايا غير موجودة في الـ spec.
- لا تفترض تفاصيل الحلقة أو الدروس من عندك.
- لا تجعل الفيديو يصل للمعلم قبل موافقة ولي الأمر.
- لا تجعل الأمنيات وعدًا ماديًا مضمونًا.
- لا تعرض بيانات طفل لولي أمر ليس مرتبطًا به.
- لا تعرض فيديوهات أو أمنيات أو ملاحظات خاصة لضيف الشرف.
- لا تستخدم English UI labels إلا عند الضرورة التقنية.
- لا تبنِ تصميمًا أخضر/ذهبيًا تقليديًا. الهوية بنفسجية.
- لا تجعل التصميم لعبة أو كرتونيًا بزيادة.

## قبل كتابة الكود

عند أي Feature جديدة:

1. اقرأ ملف المتطلبات الخاص بها.
2. اعرض خطة تنفيذ.
3. اذكر الملفات التي ستنشئها أو تعدلها.
4. اذكر الـ edge cases.
5. انتظر الموافقة قبل التنفيذ إذا كانت المهمة كبيرة.

## بعد كل Task

يجب أن تعرض:

- الملفات المعدلة.
- ملخص التغيير.
- أي أخطاء أو افتراضات.
- خطوات التحقق.
- نتيجة build/lint إن كانت متاحة.

## التقنية المفضلة

- Next.js + TypeScript.
- RTL Arabic first.
- Firebase لاحقًا للـ Auth / Firestore / Storage / Messaging.
- Design System بمكونات قابلة لإعادة الاستخدام.
- لا تخلط business logic داخل UI components.

## الهوية

- الاسم: الأشبال.
- الخط: Baloo / Baloo Bhaijaan 2 للواجهة العربية.
- الألوان: بنفسجي وبنفسجي غامق كأساس.
- الشكل: Premium, warm, safe, child-friendly, not childish.
- عناصر التصميم: دوائر، كروت rounded، glow خفيف، أوسمة، تقدم.

## الأدوار

## قاعدة الخصوصية

الخصوصية أهم من جمال الواجهة. أي ميزة تمس الأطفال أو الفيديو أو الأمنيات يجب أن تكون parent-controlled ومحدودة الصلاحية.
