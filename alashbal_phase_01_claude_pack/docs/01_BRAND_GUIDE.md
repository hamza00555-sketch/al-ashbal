# Brand Guide — الأشبال

## الاسم

الأشبال

## الشخصية

- آمن.
- دافئ.
- محفز.
- محترم.
- طفولي بذكاء، وليس طفوليًا بشكل ساذج.
- حديث ومناسب لتطبيق عائلي تعليمي.

## الفايب البصري

Premium Purple Learning App

الهوية يجب أن تجمع بين:

- عالم أطفال محترم.
- تعلم قرآن وتجويد وسلوك.
- شعور بالإنجاز.
- نظام واضح للأهل والمعلمين.

## قاعدة اللون

- أغلب الواجهة بنفسجي أو بنفسجي غامق.
- الأبيض يستخدم فقط لبعض الكروت المهمة، وليس كل الواجهة.
- الذهبي للأوسمة والإنجازات فقط.
- الأخضر/المنت لحالات النجاح.
- الأحمر/الكورال للتنبيهات أو الرفض اللطيف.

## الخط

- Baloo / Baloo Bhaijaan 2.
- واجهة عربية RTL.
- النصوص يجب أن تكون واضحة وليست مزخرفة.

## عناصر التصميم

- دوائر.
- Progress rings.
- Rounded cards.
- Soft glow.
- Badges.
- Subtle stars.
- عناصر إسلامية خفيفة جدًا، لا زخرفة ثقيلة.

## ممنوعات الهوية

- لا Green Islamic App تقليدي.
- لا زخرفة ذهبية مبالغ فيها.
- لا Mascot ضخم يسرق الواجهة.
- لا Game UI طفولي جدًا.
- لا Dark mode كامل بلا تباين.

## الصور المرجعية

راجع الصور داخل:

```txt
assets/visual-reference/
```

هذه صور concept وليست UI نهائي. الهدف منها تثبيت الفايب العام، وليس نسخ كل تفصيل حرفيًا.
