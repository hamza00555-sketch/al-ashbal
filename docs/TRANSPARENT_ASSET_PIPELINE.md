# TRANSPARENT ASSET PIPELINE — الأشبال

> هدف هذه الوثيقة: إخراج الأصول الصغيرة **جاهزة للاستخدام مباشرة** داخل التطبيق —
> PNG بخلفية شفافة، مقصوصة، حواف نظيفة — **بلا أي قص يدوي** من المستخدم.

ينطبق على: **icons · badges · avatars · empty-state objects · small feature
illustrations**. الخلفيات (backgrounds) **مستثناة** (تبقى مشهدًا كاملًا غير شفاف).

---

## المبدأ

نماذج التوليد لا تُخرج دائمًا خلفية شفافة موثوقة. لذلك البايبلاين خطوتان آليتان:

1. **Generate** الأصل كجسم 3D لطيف **في وسط خلفية سادة نظيفة** (لون موحّد سهل
   القص، مثل أبيض/رمادي فاتح محايد) — وليس مشهدًا.
2. **Cutout** آليًا عبر `mcp__Higgsfield__remove_background` على `job_id` الناتج
   → يعيد صورة **بخلفية شفافة** (job/media جديد).
3. **Save** الـ PNG الشفاف في مجلد الأصل داخل المشروع بالاسم المعتمد.

> لا تُسلَّم الأصول على خلفية ملوّنة من الباليت (يصعب قصّها)؛ تُولَّد على خلفية
> سادة محايدة ثم تُقص. النتيجة النهائية شفافة.

## خطوات التنفيذ (Higgsfield)

```
# 1) توليد على خلفية نظيفة (flux_2 للستايل 3D اللطيف)
generate_image {
  model: "flux_2", resolution: "1k", aspect_ratio: "1:1",
  prompt: "<subject> … centered, isolated on a plain flat light-gray studio
           background, even soft lighting, no scene, no shadow on backdrop"
}  → job_id

# 2) قص الخلفية آليًا
remove_background { media_id: <job_id>, media_type: "image" }  → cutout_job_id

# 3) حفظ الناتج الشفاف
#    (تنزيل cutout الناتج → assets/generated/<category>/<name>.png)
```

ملاحظة بيئية: في بيئة التشغيل الحالية (sandbox) **يُحجب نطاق Higgsfield CDN
(HTTP 403)** فيتعذّر تنزيل الملف داخل المستودع تلقائيًا من هنا. لذلك:
- الخطوتان 1 و2 تُنفَّذان وتُنتجان الأصل الشفاف على Higgsfield (قابل للعرض/المراجعة).
- الخطوة 3 (الحفظ في المستودع) تتم من بيئة بها وصول شبكي، أو تُنزَّل الأصول دفعة
  واحدة لاحقًا إلى مجلداتها. أسماء الملفات ومساراتها محجوزة مسبقًا في الجرد.

بديل عند توفّر مفتاح: مهارة `gpt-image-2` (تتطلب `FAL_KEY`) + خطوة remover —
لكن SETUP يذكر أنها لا تُخرج شفافية حقيقية، فتبقى خطوة الـ cutout ضرورية.

## File Output Rules

- الصيغة: **PNG** (32-bit مع قناة ألفا).
- الخلفية: **شفافة بالكامل**.
- القص: **tight crop** حول الجسم مع هامش بسيط متناسق.
- الحواف: **نظيفة**، بلا matte halo ولا حافة بيضاء/رمادية.
- الحجم: حسب الجرد (أيقونات 512²، أوسمة/أفاتارات 512²، رسومات 800–1024).
- جاهز للاستخدام مباشرة في `<img>`/`next/image` داخل التطبيق (لاحقًا، ليس الآن).

## Backgrounds (استثناء)

- مشهد/تدرّج كامل، **غير شفاف**، لا remove_background، لا قص.
- صيغة PNG أو JPG، أبعاد رأسية/أفقية حسب الشاشة.
